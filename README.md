# daily-saas-ideas

Daily SaaS Ideas Collection - Validated Micro-SaaS Concepts for Solo Founders

## Features

- Collection of validated micro-SaaS ideas with revenue data
- Detailed analysis pages for each idea (problem, solution, pricing, tech stack, validation plan)
- Built with Next.js 15, shadcn/ui, and Tailwind CSS
- Deployed on Vercel with automatic deployments on push

## Tech Stack

- Next.js 15 (App Router)
- shadcn/ui components
- Tailwind CSS v4
- TypeScript
- Vercel (deployment)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Pages

- `/` - Home page with ideas grid
- `/ideas/1` - Detailed analysis of Idea #1: Testimonial Widget for EU Freelancers

## Deployment

Connected to Vercel for automatic deployments on push to `master` branch.
